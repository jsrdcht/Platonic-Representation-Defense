# The Platonic Defense

Official implementation of **"The Platonic Defense: Backdoor Defense for Self-Supervised Encoders in the Era of Large Scale Pre-training"**.

> We propose an attack-agnostic, model-agnostic, and modality-agnostic black-box test-time backdoor defense paradigm, called **Platonic Representation Defense**, inspired by the Platonic Representation Hypothesis. It performs both representation **detection** and **purification** via a conditional energy function trained with noise-contrastive estimation and denoising score matching.
